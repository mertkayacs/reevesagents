## ما هو ReevesAgents

- مساحة عمل محلية مجانية لوكلاء برمجة AI (Claude Code وCodex وHermes وDeepSeek وKimi وغيرها). تعمل جنبًا إلى جنب على جهازك.
- الفكرة الأبرز: وكيل واحد ينشئ الآخرين ويقودهم. يستطيع وكيل Claude Code بدء فريق من وكلاء Codex وClaude Code وتوجيهه على مهام منفصلة.
- يعمل فوق أدوات CLI الحقيقية الموجودة لديك أصلًا. يبقى تسجيل الدخول إلى المزوّد ضمن كل CLI. لا يخزّن ReevesAgents أي مفاتيح API ولا يمرّر حركة النماذج عبر وسيط.
- بلا قاعدة بيانات، وبلا Docker، وبلا خدمة في الخلفية. الحالة ملفات JSON محلية تحت `~/.reeves`.

## قبل أن تبدأ

- macOS أو Linux أو WSL (نظام Windows الأصلي ليس الهدف؛ استخدم WSL).
- Node.js 20.19 أو أحدث.
- tmux 3.0 أو أحدث.
- أداة CLI واحدة على الأقل من مزوّد، مثبّتة وموثّقة: Claude Code أو Codex أو OpenCode أو Hermes أو Kimi أو DeepSeek أو Pi أو Qwen أو Aider.

## التثبيت والتحقق

- ثبّته تثبيتًا عامًا: `npm install -g reevesagents`
- افحص جهازك: `reevesagents doctor` (يتحقق من Node وtmux ومجلد الحالة وأدوات CLI للمزوّدين التي يراها).
- شغّله: `reevesagents`
- أتفضّل pnpm أو Yarn أو Bun أو npx أو Homebrew؟ انظر [التثبيت](i18n/README.ar.md#التثبيت) في README.

## تشغيلتك الأولى

أسرع تشغيلة قابلة للتكرار تكون من سطر الأوامر. للتشغيلة وكيل قائد واحد وأي عدد من العاملين؛ ويُكتب كل وكيل بالصيغة `provider[:nickname[:model]]`:

```sh
reevesagents spawn claude-code:lead codex:worker \
  --name "first run" \
  --prompt "Say hello and list the files in this folder."
```

- `claude-code:lead` هو القائد، و`codex:worker` عامل. وإن لم يُسمَّ أي وكيل، كان الافتراضي `codex`.
- يسمّي `--name` التشغيلة، ويحدّد `--cwd` مجلد العمل (الافتراضي مكانك الحالي)، ويُلصق `--prompt` في كل وكيل.

أتفضّل بداية مرئية؟ شغّل `reevesagents` لواجهة TUI أو `reevesagents web` لواجهة Web UI المحلية وأنشئ التشغيلة من هناك.

## الطرق الخمس لاستخدامه

تصل إلى التشغيلات نفسها عبر خمس واجهات. اختر منها ما يناسب اللحظة:

- **TUI** (`reevesagents`): تحكّم سريع يعتمد لوحة المفاتيح أولًا داخل الطرفية.
- **Web UI** (`reevesagents web`): عرض مرئي موحّد للتشغيلات والوكلاء واللوحات الحية والسجل. محلي ومقتصر على loopback.
- **CLI** (`reevesagents spawn` و`runs` و`peek` و`open` و`stop`): البرامج النصية والأوامر السريعة وفحوصات السلامة.
- **tmux**: كل وكيل هو CLI حقيقي في لوحة tmux خاصة به، فتظل الجلسات تعمل محليًا حتى بعد إغلاق TUI أو Web UI.
- **Agent control** (`reevesagents attach <cli>`): آلية MCP الاختيارية التي تدع وكيلًا واحدًا يقود الباقي. يتناولها القسم التالي.

## دع وكيلًا واحدًا يقود الباقي

هذه هي الميزة الأساسية، وتبقى معطّلة حتى تفعّلها.

- فعّلها لأداة CLI لديك: `reevesagents attach claude` (أو `reevesagents attach` لوصل كل CLI مثبّت قادر على استضافتها). يمكنك ذلك أيضًا من شاشة **Agent control** في TUI أو Web UI.
- تأكّد منها: يسرد `reevesagents hosts` أدوات CLI على جهازك ويبيّن أيّها متصل.
- أعد تحميل CLI لديك: أعد تشغيل الجلسة حتى تلتقط الأدوات الجديدة (يستخدم هذا بروتوكول MCP، وهو الطريقة القياسية التي تعرض بها أداةُ وكيلٍ أوامرَها لأداة أخرى).
- الآن يستطيع وكيلك إنشاء وكلاء آخرين وقيادتهم: ابدأ وكيلًا على مهمة، وأرسل إليه نصًا أو ضغطات مفاتيح، واقرأ ما يفعله، ووافق على ما يطلبه أو ارفضه.

مثال عملي: اربط Claude Code وأعد تشغيله، ومن داخل جلسة Claude Code واحدة يمكنك إنشاء وكيل Codex على مشكلة ووكيل Claude Code ثانٍ على أخرى، ثم مراقبة الاثنين وتوجيههما.

- أدوات CLI القادرة على استضافة هذا اليوم: claude وcodex وkimi وqwen وopencode وhermes. يُربط OpenCode يدويًا، لأن خطوة الإضافة عنده تفاعلية.
- لا يحصل العاملون على هذه الأدوات افتراضيًا، فلا يستطيع عامل إنشاء وكلاء إضافيين. ولكي تدع عاملًا يقود وكلاءه الفرعيين، اربط الـ MCP بأداة CLI ذلك العامل أيضًا.
- لقطع الاتصال لاحقًا: `reevesagents detach claude`.

## المهام اليومية

- اعرف ما يعمل الآن: `reevesagents runs` (أضف `--json` للبرامج النصية).
- راقب وكيلًا واحدًا دون مغادرة صدفتك: `reevesagents peek <agent> -n 40`.
- اقفز إلى لوحة tmux الخاصة بوكيل: `reevesagents open <agent>`.
- أوقف تشغيلة كاملة: `reevesagents stop <run> --yes`.
- أوقف وكيلًا واحدًا: `reevesagents kill <agent> --yes`.
- اعرف ما يطلبه الوكلاء: `reevesagents approvals`، ثم `approve <id>` أو `deny <id>`.
- ينهي `stop` و`kill` العمل، وتزيل أوامر `delete` السجلات المنتهية. وكلها ترفض العمل بدون `--yes`.

## الحفاظ على الكلفة منخفضة

- ضع نموذجًا أرخص أو مجانيًا في المقدمة ليوزّع العمل، ودعه يسلّم المهام الثقيلة إلى وكيل أقوى عند الحاجة فقط.
- دع النماذج الرخيصة تكتب الكود الروتيني والاختبارات بينما تخطط أنت وتصمّم بنموذج أكبر، بدلًا من دفع كل شيء عبر نموذج افتراضي واحد مكلف.
- تبقى حصص المزوّد وفوترته ضمن كل CLI، ولا يضيف ReevesAgents أي كلفة من عنده.

## حين يبدو شيء غير صحيح

- شغّل `reevesagents doctor` أولًا. يفحص Node وtmux ومجلد الحالة وأدوات CLI للمزوّدين لديك، ويخبرك بما يفشل.
- **tmux مفقود:** ثبّته (`brew install tmux` أو `apt install tmux`) وشغّل doctor مجددًا.
- **مزوّد لم يُكتشف:** لا يطلق ReevesAgents سوى أدوات CLI الموجودة على `PATH` لديك والموثّقة. ثبّت تلك الأداة أو سجّل الدخول إليها.
- **تبلّغ Web UI عن حزم مفقودة:** تحتاج إلى `ws` و`@lydell/node-pty`. أعد التثبيت مع تمكين التبعيات الاختيارية.
- **المنفذ مستخدم بالفعل:** يبدأ `reevesagents web` على `8080` ويرجع إلى المنفذ الحر التالي؛ مرّر `--port <n>` لاختيار منفذ آخر.
- مزيد من التفاصيل في [استكشاف الأخطاء](i18n/README.ar.md#استكشاف-الأخطاء-وإصلاحها).
