## ما هو ReevesAgents

- مساحة عمل محلية مجانية لوكلاء برمجة AI (Claude Code وCodex وHermes وDeepSeek وKimi وغيرها). تعمل جنبًا إلى جنب على آلتك.
- الفكرة الأساسية: وكيل واحد ينشئ ويقود الآخرين. وكيل Claude Code يمكنه أن يبدأ ويوجّه فريقًا من وكلاء Codex وClaude Code على مهام منفصلة.
- يعمل على أساس أدوات CLI الحقيقية التي لديك بالفعل. بقاء تسجيل الدخول إلى المزوّد مع كل CLI. لا يخزّن ReevesAgents أي مفاتيح API ولا يمرّر حركة النماذج عبر وكيل.
- لا قاعدة بيانات، لا Docker، لا خدمة في الخلفية. الحالة ملفات JSON محلية تحت `~/.reeves`.

## قبل أن تبدأ

- macOS أو Linux أو WSL (نظام Windows الأصلي ليس الهدف؛ استخدم WSL).
- Node.js 20.19 أو أحدث.
- tmux 3.0 أو أحدث.
- أداة CLI واحدة على الأقل مثبّتة وموثّقة: Claude Code أو Codex أو OpenCode أو Hermes أو Kimi أو DeepSeek أو Pi أو Qwen أو Aider.

## التثبيت والتحقق

- ثبّتها عامًا: `npm install -g reevesagents`
- تحقّق من آلتك: `reevesagents doctor` (يتحقّق من Node وtmux ومجلد الحالة وأدوات CLI للمزوّد التي يمكنه رؤيتها).
- شغّلها: `reevesagents`
- تفضّل pnpm أو Yarn أو Bun أو npx أو Homebrew؟ انظر [التثبيت](../README.ar.md#التثبيت) في README.

## تشغيلتك الأولى

أسرع تشغيلة قابلة للتكرار هي من سطر الأوامر. لكل تشغيلة وكيل قائد وأي عدد من الوكلاء العاملين؛ كل وكيل مكتوب كـ `provider[:nickname[:model]]`:

```sh
reevesagents spawn claude-code:lead codex:worker \
  --name "first run" \
  --prompt "Say hello and list the files in this folder."
```

- `claude-code:lead` هو القائد، `codex:worker` هو عامل. بدون وكيل مسمى، التشغيلة الافتراضية `codex`.
- `--name` يسمّي التشغيلة، `--cwd` يضع المجلد الحالي (الافتراضي حيث أنت)، و`--prompt` يُلصق في كل وكيل.

تفضّل البداية البصرية؟ شغّل `reevesagents` لواجهة TUI أو `reevesagents web` لواجهة Web UI المحلية وأنشئ التشغيلة من هناك.

## الطرق الأربع لاستخدامه

تصل إلى التشغيلات ذاتها عبر أربع واجهات. اختر أيهما يناسب اللحظة:

- **TUI** (`reevesagents`): تحكّم سريع يعتمد لوحة المفاتيح أولًا داخل الطرفية.
- **Web UI** (`reevesagents web`): عرض بصري موحّد للتشغيلات والوكلاء واللوحات الحية والسجل. محلي ومقتصر على loopback فقط.
- **CLI** (`reevesagents spawn` و`runs` و`peek` و`open` و`stop`): البرمجة النصية والأوامر السريعة وفحوصات الصحة.
- **tmux**: كل وكيل هو CLI حقيقي في نافذة tmux خاصة به، لذا تبقى التشغيلات تعمل محليًا حتى بعد أن تغلق واجهة TUI أو Web UI.

## دع وكيلًا واحدًا يقود الباقي

هذه الميزة الأساسية، وتبقى معطّلة حتى تشغّلها.

- شغّلها لـ CLI الخاص بك: `reevesagents attach claude` (أو `reevesagents attach` لربط كل CLI مثبّت يمكنه استضافتها). يمكنك فعل هذا أيضًا من شاشة **Agent control** في TUI أو Web UI.
- تأكّد من ذلك: `reevesagents hosts` يسرد أدوات CLI على آلتك ويوضح أيها متصلة.
- أعد تحميل CLI الخاص بك: أعد تشغيل الجلسة لتحميل الأدوات الجديدة (هذا يستخدم MCP، الطريقة الموحّدة التي تعرّض أداة وكيل واحد الأوامر لآخر).
- الآن وكيلك يمكنه أن ينشئ ويقود وكلاء آخرين: ابدأ وكيلًا على مهمة، أرسل له نصًا أو ضغطات مفاتيح، اقرأ ما يفعله، وافق أو ارفض ما يطلبه.

مثال تطبيقي: ربط Claude Code وأعد تشغيله، ومن داخل جلسة Claude Code واحدة يمكنك إنشاء وكيل Codex على مشكلة واحدة ووكيل Claude Code ثاني على أخرى، ثم شاهد وغيّر الاتجاه لكليهما.

- أدوات CLI التي يمكنها استضافة هذا الآن: claude و codex و kimi و qwen و opencode و hermes. OpenCode يُربط يدويًا، لأن خطوة الإضافة الخاصة به تفاعلية.
- العاملون لا يحصلون على هذه الأدوات افتراضيًا، لذا عامل لا يمكنه إنشاء وكلاء آخرين. لكي تسمح لعامل بأن يقود وكلاء فرعيين خاصة به، ربط MCP بـ CLI ذلك العامل أيضًا.
- للقطع الاتصال لاحقًا: `reevesagents detach claude`.

## المهام اليومية

- انظر ما يعمل: `reevesagents runs` (أضف `--json` للبرامج النصية).
- راقب وكيلًا واحدًا دون مغادرة الصدفة: `reevesagents peek <agent> -n 40`.
- انتقل إلى نافذة tmux الخاصة بوكيل: `reevesagents open <agent>`.
- أوقف تشغيلة كاملة: `reevesagents stop <run> --yes`.
- أوقف وكيلًا واحدًا: `reevesagents kill <agent> --yes`.
- `stop` و`kill` هما الأمران المدمّران الوحيدان، لذا يرفضان بدون `--yes`.

## الحفاظ على الكلفة منخفضة

- ضع نموذجًا أرخص أو مجانيًا في المقدمة لتوجيه العمل، واسمح له بتسليم المهام الثقيلة إلى وكيل أقوى فقط عند الحاجة.
- دع النماذج الرخيصة تكتب الكود الروتيني والاختبارات بينما تخطط وتصمّم بنموذج أكبر، بدلًا من دفع كل شيء عبر نموذج افتراضي واحد مكلف.
- الحصص والفواتير تبقى مع كل CLI. لا يضيف ReevesAgents أي كلفة بنفسه.

## حين يبدو شيء غير صحيح

- شغّل `reevesagents doctor` أولًا. يفحص Node وtmux ومجلد الحالة وأدوات CLI من المزوّدين، ويخبرك ما يفشل.
- **tmux مفقود:** ثبّته (`brew install tmux` أو `apt install tmux`) وشغّل doctor مجددًا.
- **مزوّد لم يُكتشف:** ReevesAgents يطلق فقط أدوات CLI التي توجد على `PATH` الخاص بك وموثّقة. ثبّت أو سجّل الدخول إلى ذلك CLI.
- **Web UI يبلّغ عن حزم مفقودة:** تحتاج إلى `ws` و`@lydell/node-pty`. أعد التثبيت مع تمكين التبعيات الاختيارية.
- **المنفذ مستخدم بالفعل:** `reevesagents web` يبدأ على `8080` ويرجع إلى المنفذ الحر التالي؛ مرّر `--port <n>` لاختيار آخر.
- المزيد من التفاصيل في [استكشاف الأخطاء](../README.ar.md#استكشاف-الأخطاء-وإصلاحها).
