# دليل ReevesAgents للمستخدمين

[English](GUIDE.md) · [Deutsch](GUIDE.de.md) · [Français](GUIDE.fr.md) · [Español](GUIDE.es.md) · [Português](GUIDE.pt.md) · [Italiano](GUIDE.it.md) · [Türkçe](GUIDE.tr.md) · [Русский](GUIDE.ru.md) · [简体中文](GUIDE.zh-Hans.md) · **العربية**

يأخذك هذا الدليل من التثبيت الأول إلى اللحظة التي يتولى فيها وكيل واحد تشغيل الباقي نيابة عنك. أما حين تريد كل أمر وكل خيار، فذلك كله في [README](i18n/README.ar.md).

## ما هو ReevesAgents

- مساحة عمل محلية مجانية يعمل فيها وكلاء البرمجة لديك (Claude Code وCodex وHermes وDeepSeek وKimi وغيرها) جنبًا إلى جنب على جهازك.
- يمكن لوكيل واحد إنشاء الآخرين وقيادتهم عبر MCP. على سبيل المثال، تستطيع جلسة Claude Code تشغيل وكلاء Codex وClaude Code على مهام منفصلة.
- ويمكنك استخدام ReevesAgents أيضًا كمساحة عمل عادية: أنشئ الوكلاء الذين تريدهم وواصِل إضافة المزيد بـ `reevesagents add`. يعملون جنبًا إلى جنب، ولا يتحكم أحد في أحد حتى تختار تفعيل الـ MCP.
- وهو يقوم فوق أدوات CLI الموجودة لديك أصلًا، فيبقى كل تسجيل دخول في مكانه المعهود. لا يحمل ReevesAgents مفتاح API أبدًا، ولا يمسّ حركة النماذج لديك.
- وحالته كلها قدر يسير من JSON تحت `~/.reeves`، فلا قاعدة بيانات تديرها، ولا Docker تسحبه، ولا شيء يقبع في الخلفية.

## قبل أن تبدأ

- macOS أو Linux أو WSL (نظام Windows الأصلي ليس الهدف؛ استخدم WSL).
- Node.js 20.19 أو أحدث.
- tmux 3.0 أو أحدث.
- أداة CLI واحدة على الأقل من مزوّد، مثبّتة وموثّقة: Claude Code أو Codex أو OpenCode أو Hermes أو Kimi أو DeepSeek أو Pi أو Qwen أو Aider.

## التثبيت والتحقق

- ثبّته عبر Homebrew: `brew install mertkayacs/reevesagents/reevesagents`، أو تثبيتًا عامًا بمدير حزم Node مثل pnpm: `pnpm add -g reevesagents`
- افحص جهازك: `reevesagents doctor` (يتحقق من Node وtmux ومجلد الحالة وأدوات CLI للمزوّدين التي يراها).
- شغّله: `reevesagents`
- أتفضّل npm أو Yarn أو Bun أو npx؟ انظر [التثبيت](i18n/README.ar.md#التثبيت) في README.

## تشغيلتك الأولى

أسرع تشغيلة يمكنك تكرارها تبدأ من سطر الأوامر. لكل تشغيلة وكيل قائد واحد وأي عدد من العاملين، ويُكتب كل وكيل بالصيغة `provider[:nickname[:model]]`:

```sh
reevesagents spawn claude-code:lead codex:worker \
  --name "first run" \
  --prompt "Say hello and list the files in this folder."
```

- `claude-code:lead` هو القائد، و`codex:worker` عامل. وإن لم يُسمَّ أي وكيل، كان الافتراضي `codex`.
- يسمّي `--name` التشغيلة، ويحدّد `--cwd` مجلد العمل (الافتراضي مكانك الحالي)، ويُلصق `--prompt` في كل وكيل.

أتفضّل بداية مرئية؟ شغّل `reevesagents` لواجهة TUI أو `reevesagents web` لواجهة Web UI المحلية وأنشئ التشغيلة من هناك.

ألا تريد التخطيط للفريق كله سلفًا؟ أنشئ وكيلًا واحدًا ووسّع مساحة العمل تدريجيًا. ينضم `add` إلى أحدث تشغيلة لديك، فلا يوجد معرّف تشغيلة تنسخه:

```sh
reevesagents spawn claude-code:lead
reevesagents add codex:worker
```

## الطرق الخمس لاستخدامه

تصل إلى التشغيلات نفسها عبر خمس واجهات. اختر منها ما يناسب اللحظة:

- **TUI** (`reevesagents`): تطبيق الطرفية الذي يقضي فيه معظم المستخدمين وقتهم. كل شيء فيه قائمة ظاهرة، فمفاتيح الأسهم كل ما تحتاج إليه.
- **Web UI** (`reevesagents web`): التشغيلات نفسها على صفحة متصفح واحدة، مع إطلالة حية على أي وكيل. وهي لا تجيب إلا على loopback.
- **CLI** (`reevesagents spawn` و`runs` و`peek` و`open` و`stop`): للبرامج النصية، ولأيام تفضّل فيها أن تكتب الأمر بدل أن تتصفح.
- **tmux**: هنا يعيش الوكلاء فعلًا. ولأن كل واحد منهم CLI حقيقي في لوحته الخاصة، فإن إغلاق TUI أو Web UI لا يقاطع أحدًا.
- **Agent control** (`reevesagents attach <cli>`): آلية MCP الاختيارية التي تدع وكيلًا واحدًا يقود الباقي. ويتناولها القسم التالي خطوة خطوة.

## دع وكيلًا واحدًا يقود الباقي

هذه هي الميزة الأساسية، وتبقى معطّلة حتى تفعّلها.

- فعّلها لأداتك بالأمر `reevesagents attach claude`، أو شغّل `reevesagents attach` وحده ليوصل كل CLI مثبّت يستطيع استضافتها. وتؤدي شاشة **Agent control** في TUI وWeb UI الدور نفسه.
- ويريك `reevesagents hosts` أين تقف: كل أدوات CLI على الجهاز، وأيّها متصل.
- ثم أعد تشغيل تلك الأداة مرة واحدة، لأن الأدوات لا تُلتقط إلا عند بدء الجلسة (هذا MCP عادي، وهو الطريقة القياسية التي تعرض بها أداةُ وكيلٍ أوامرَها لأداة أخرى).
- ومن تلك اللحظة يستطيع وكيلك أن يضع وكيلًا جديدًا على مهمة، ويكتب إليه، ويقرأ ما يفعله، ويوافق على ما يطلبه أو يرفضه.

مثال عملي: اربط Claude Code وأعد تشغيله، ومن داخل جلسة Claude Code واحدة يمكنك إنشاء وكيل Codex على مشكلة ووكيل Claude Code ثانٍ على أخرى، ثم مراقبة الاثنين وتوجيههما.

- أدوات CLI القادرة على استضافة هذا اليوم: claude وcodex وkimi وqwen وopencode وhermes. يُربط OpenCode يدويًا، لأن خطوة الإضافة عنده تفاعلية.
- لا يحصل العاملون على هذه الأدوات افتراضيًا، فلا يستطيع عامل إنشاء وكلاء إضافيين. ولكي تدع عاملًا يقود وكلاءه الفرعيين، اربط الـ MCP بأداة CLI ذلك العامل أيضًا.
- لقطع الاتصال لاحقًا: `reevesagents detach claude`.

## المهام اليومية

- اعرف ما يعمل الآن: `reevesagents runs` (أضف `--json` للبرامج النصية).
- راقب وكيلًا واحدًا دون مغادرة صدفتك: `reevesagents peek <agent> -n 40`.
- اقفز إلى لوحة tmux الخاصة بوكيل: `reevesagents open <agent>`.
- أوقف تشغيلة كاملة: `reevesagents stop <run> --yes`.
- أوقف وكيلًا واحدًا: `reevesagents kill <agent> --yes`.
- اعرف ما يطلبه الوكلاء: `reevesagents approvals`، ثم `approve <id>` أو `deny <id>`.
- ينهي `stop` و`kill` العمل، وتزيل أوامر `delete` السجلات المنتهية. وكلها ترفض العمل بدون `--yes`.

## الحفاظ على الكلفة منخفضة

- ضع نموذجًا رخيصًا أو مجانيًا في المقدمة موزِّعًا للعمل، ولا تدعه يوقظ النموذج الغالي إلا حين تستحق المهمة ذلك فعلًا.
- فالكود الروتيني والاختبارات هي بالضبط ما وُجدت النماذج الأرخص من أجله. وفّر النموذج الكبير للتخطيط والتصميم بدل أن تدفع له ليكتب الكود المتكرر.
- ومهما كلّفك هذا، فهو الفوترة الاعتيادية نفسها عند مزوّديك، وReevesAgents نفسه لا يضيف شيئًا فوقها.

## حين يبدو شيء غير صحيح

- ابدأ بـ `reevesagents doctor`، فهو يسمّي لك المشكلة بنفسه في الغالب: يفحص Node وtmux ومجلد الحالة وكل أداة CLI من المزوّدين لديك.
- **tmux مفقود:** ثبّته (`brew install tmux` أو `apt install tmux`) ودع doctor يؤكد لك النتيجة.
- **مزوّد لم يُكتشف:** السبب يكاد يكون دائمًا أنه غير مثبّت أو غير مسجّل الدخول، لأن ReevesAgents لا يطلق إلا الأدوات الموجودة على `PATH` لديك والموثّقة.
- **تبلّغ Web UI عن حزم مفقودة:** جرى تخطي الوحدتين الاختياريتين `ws` و`@lydell/node-pty` وقت التثبيت، وإعادة التثبيت على نحو اعتيادي تعيدهما في العادة.
- **المنفذ مستخدم بالفعل:** لا خطب هنا، إذ يأخذ `reevesagents web` ببساطة المنفذ الحر التالي ويطبع الرابط. مرّر `--port <n>` إن كنت تريد منفذًا بعينه.
- مزيد من التفاصيل في [استكشاف الأخطاء](i18n/README.ar.md#استكشاف-الأخطاء-وإصلاحها).
