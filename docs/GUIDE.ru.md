# Руководство пользователя ReevesAgents

[English](GUIDE.md) · [Deutsch](GUIDE.de.md) · [Français](GUIDE.fr.md) · [Español](GUIDE.es.md) · [Português](GUIDE.pt.md) · [Italiano](GUIDE.it.md) · [Türkçe](GUIDE.tr.md) · **Русский** · [简体中文](GUIDE.zh-Hans.md) · [العربية](GUIDE.ar.md)

Простое пошаговое руководство: установите его, сделайте первый запуск и позвольте одному
агенту управлять остальными. Для полного справочника команд и параметров см.
[README](../README.ru.md).

## Что такое ReevesAgents

- Бесплатное локальное рабочее пространство для агентов AI CLI (Claude Code, Codex, Hermes,
  DeepSeek, Kimi и других). Они работают рядом на вашей машине.
- Главная идея: один агент создаёт и управляет другими. Агент Claude Code может запустить
  и направить команду агентов Codex и Claude Code на отдельные задачи.
- Работает поверх реальных CLI, которые у вас уже есть. Вход к провайдеру остаётся за
  каждым CLI. ReevesAgents не хранит API-ключи и никогда не проксирует трафик моделей.
- Без базы данных, без Docker, без фонового сервиса. Состояние хранится локально в JSON под
  `~/.reeves`.

## Перед началом

- macOS, Linux или WSL (нативный Windows не является целевой средой; используйте WSL).
- Node.js версии 20.19 или новее.
- tmux версии 3.0 или новее.
- По крайней мере один установленный и авторизованный провайдерский CLI: Claude Code, Codex,
  OpenCode, Hermes, Kimi, DeepSeek, Pi, Qwen или Aider.

## Установка и проверка

- Установите глобально: `npm install -g reevesagents`
- Проверьте вашу машину: `reevesagents doctor` (проверяет Node, tmux, папку состояния и
  какие провайдерские CLI видны).
- Запустите: `reevesagents`
- Предпочитаете pnpm, Yarn, Bun, npx или Homebrew? См. [Установка](../README.ru.md#установка)
  в README.

## Первый запуск

Самый быстрый повторяемый запуск — из командной строки. Запуск состоит из одного ведущего агента
и любого количества рабочих; каждый агент записывается как `provider[:nickname[:model]]`:

```sh
reevesagents spawn claude-code:lead codex:worker \
  --name "first run" \
  --prompt "Say hello and list the files in this folder."
```

- `claude-code:lead` — ведущий, `codex:worker` — рабочий. Если агента не назвать, запуск по умолчанию
  использует `codex`.
- `--name` помечает запуск, `--cwd` устанавливает рабочую папку (по умолчанию текущая директория),
  и `--prompt` вставляется в каждого агента.

Предпочитаете визуальный старт? Запустите `reevesagents` для TUI или `reevesagents web` для
локального Web UI и создайте запуск там.

## Четыре способа использования

К одним и тем же запускам можно подойти через четыре поверхности. Выбирайте ту, которая подходит
в данный момент:

- **TUI** (`reevesagents`): быстрое управление с приоритетом клавиатуры прямо в терминале.
- **Web UI** (`reevesagents web`): один визуальный обзор запусков, агентов, живых панелей
  и истории. Локальный и только на петлевом интерфейсе.
- **CLI** (`reevesagents spawn`, `runs`, `peek`, `open`, `stop`): скрипты, быстрые команды
  и проверки здоровья.
- **tmux**: каждый агент — это реальный CLI в собственной панели tmux, так что сессии продолжают
  работать локально даже после закрытия TUI или Web UI.

## Позвольте одному агенту управлять остальными

Это основная функция, и она выключена, пока вы её не включите.

- Включите для вашего CLI: `reevesagents attach claude` (или `reevesagents attach` для подключения
  каждого установленного CLI, который он может размещать). Вы также можете сделать это с экрана
  **Agent control** в TUI или Web UI.
- Подтвердите: `reevesagents hosts` перечисляет CLI на вашей машине и показывает, какие из них
  подключены.
- Перезагрузите ваш CLI: перезапустите сессию, чтобы она подхватила новые инструменты (это использует
  MCP, стандартный способ, которым один агентский инструмент предоставляет команды другому).
- Теперь ваш агент может создавать и управлять другими агентами: запустить агента на задачу,
  отправить ему текст или нажатия клавиш, прочитать, что он делает, и одобрить или отклонить
  его запросы.

Практический пример: подключитесь к Claude Code, перезагрузитесь и из одной сессии Claude Code
вы можете запустить агента Codex на одной проблеме и второго агента Claude Code на другой,
затем наблюдать и направлять обоих.

- CLI, которые могут размещать это сегодня: claude, codex, kimi, qwen, opencode, hermes.
  OpenCode подключается вручную, так как его собственный шаг добавления интерактивен.
- Рабочие по умолчанию не получают эти инструменты, так что рабочий не может запустить больше
  агентов. Чтобы позволить рабочему управлять собственными суб-агентами, подключите MCP к CLI
  этого рабочего тоже.
- Чтобы отключиться позже: `reevesagents detach claude`.

## Повседневные задачи

- Посмотрите, что работает: `reevesagents runs` (добавьте `--json` для скриптов).
- Наблюдайте за одним агентом, не покидая оболочку: `reevesagents peek <agent> -n 40`.
- Перейдите в панель tmux агента: `reevesagents open <agent>`.
- Остановите весь запуск: `reevesagents stop <run> --yes`.
- Остановите одного агента: `reevesagents kill <agent> --yes`.
- `stop` и `kill` — единственные команды, которые заканчивают работу, так что они отказываются
  работать без `--yes`.

## Сдерживание стоимости

- Поставьте более дешёвую или бесплатную модель впереди для маршрутизации работы и позвольте
  ей передавать тяжёлые задачи более умному агенту только когда необходимо.
- Позвольте дешёвым моделям писать обычный код и тесты, пока вы планируете и проектируете
  с более крупной моделью, вместо того чтобы прогонять всё через одну дорогую модель по умолчанию.
- Квоты провайдеров и биллинг остаются с каждым CLI. ReevesAgents не добавляет никаких расходов.

## Когда что-то выглядит неправильно

- Сначала запустите `reevesagents doctor`. Он проверяет Node, tmux, папку состояния и
  ваши провайдерские CLI, и сообщает вам, что не работает.
- **tmux отсутствует:** установите его (`brew install tmux` или `apt install tmux`) и
  запустите doctor снова.
- **Провайдер не обнаружен:** ReevesAgents запускает только CLI, которые находятся на вашем
  `PATH` и авторизованы. Установите или авторизуйтесь в том CLI.
- **Web UI сообщает об отсутствующих пакетах:** нужны `ws` и `@lydell/node-pty`.
  Переустановите с включёнными опциональными зависимостями.
- **Порт уже используется:** `reevesagents web` стартует на `8080` и откатывается на
  следующий свободный порт; передайте `--port <n>` для выбора другого.
- Больше деталей в [Устранение неполадок](../README.ru.md#устранение-неполадок).
